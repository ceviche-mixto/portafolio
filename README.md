# Giancarlo Larios - Portfolio V1 🚀

¡Bienvenido al código fuente de mi portafolio personal interactivo! / *Welcome to the source code of my interactive personal portfolio!*

Este proyecto sirve como una presentación bilingüe (Español/Inglés) de mi perfil como **Ingeniero de Sistemas y Computación**. Fue diseñado con un fuerte enfoque en micro-interacciones, rendimiento de interfaz y visualización de datos arquitectónicos.

---

## 🌟 Características Principales / Key Features

- **🌐 Bilingüe Nativo (i18n):** Todo el contenido de la web cambia fluidamente entre Inglés y Español sin necesidad de recargar la página, soportado por un framework de estado global.
- **✨ ScrollyTelling Interactivo:** Una sección dedicada a explicar detalladamente la arquitectura de **GRADEO** (Mi proyecto principal de reseñas anónimas). Muestra, paso a paso mediante animaciones coordinadas con el scroll, el ciclo de vida de los datos desde Next.js hasta los Edge Hooks en Vercel y Supabase.
- **📊 Live Data (Bento Grid):** Integración de animaciones que muestran métricas, lógica simulada de promedios ponderados y un componente visual de Campus usando tecnología de mapas embebida con un radar de CSS puro.
- **🕶️ Developer Mode:** Un interruptor oculto diseñado para reclutadores técnicos que transforma el contexto de la aplicación, exponiendo pseudo-código SQL, monitoreo de rendimiento simulado en consolas, y descripciones puramente arquitectónicas.
- **🎨 Animaciones Fluidas:** Interfaces orquestadas con `framer-motion`, desde el despliegue del CV por widgets hasta mallas tridimensionales de fondo (Hero Canvas).

## 🛠️ Stack Tecnológico / Tech Stack

- **Framework:** Next.js 14+ (App Router)
- **Lenguaje:** TypeScript
- **Estilos:** Tailwind CSS
- **Componentes:** Shadcn/ui & Radix UI primitives
- **Animaciones:** Framer Motion
- **Iconografía:** Lucide React
- **Estado Global:** Zustand

## 🚀 Despliegue Local / Local Deployment

Para levantar este proyecto en tu entorno local:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/ceviche-mixto/portafolio.git
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador preferido.
